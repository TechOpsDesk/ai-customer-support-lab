# Contributing

Thanks for helping improve the PixelVault AI Customer Support Lab.

Contributions are welcome. This can include bug fixes, clearer documentation, tests, accessibility improvements, new provider adapters, and verified setup notes.

## Keep the main learning path working

The main project should stay free to complete.

New tools or services should usually be added as options instead of replacing the main reference setup.

## Test your changes

If you change code, run the related tests.

If you add setup instructions, make sure they really work before adding them to the project.

## Use synthetic data only

Do not add real customer, employee, order, payment, ticket, or support data.

This project uses fictional PixelVault data only.

## Do not commit secrets

Never commit:

* API keys
* passwords
* access tokens
* private keys
* other credentials

Use local environment files such as `.env` for private settings.
