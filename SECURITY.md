# Security Policy

## Do not commit secrets

Never add private information to this repository.

This includes:

* API keys
* passwords
* access tokens
* private keys
* production credentials
* real customer information

Use environment variables or a local `.env` file for private settings.

## Use synthetic data only

This project must use fictional PixelVault data only.

Do not add real customer, employee, order, payment, ticket, or support information.

## Reporting a security problem

Do not post sensitive security problems, passwords, keys, or other private information in a public GitHub issue.

A private reporting method will be added before the first public release.
