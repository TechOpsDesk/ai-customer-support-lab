# PixelVault AI Customer Support Lab

PixelVault AI Customer Support Lab is a hands-on project for learning how AI customer support systems work.

The project uses a fictional company called **PixelVault Retro**. All customer and business data in this project is fake and made for learning.

## What this project is

This project is for support people who want to understand the technical side of AI.

We will build a small AI support system step by step.

Along the way, we will learn about:

* synthetic customer and support data
* databases
* APIs
* local AI models
* RAG
* tool calling
* support workflows
* authority and safety rules
* human handoff
* logs and monitoring
* testing
* deployment

## How we learn

This is more than a chatbot demo.

We will build the system, inspect how it works, test it, break parts of it on purpose, understand what went wrong, and then fix it.

The goal is to understand how an AI support system works in the real world.

## Reference tools

The main project will use:

* Ubuntu
* Docker
* Python
* FastAPI
* PostgreSQL
* pgvector
* Ollama
* Chatwoot
* pytest

Other tools may be added later through adapters.

## Cost

The main learning path should be possible without paying for an AI API subscription.

## Data

PixelVault Retro is fictional.

All customers, orders, tickets, products, shipments, and support messages used in this project will be synthetic.

No real customer data should be used.
